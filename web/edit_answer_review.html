Answer review

One card per visitor question the daily review flagged, with every fix it suggested. Choose one answer fix or None, tick any text edits, and press Apply: the page checks that they still fit, then measures what every FAQ title, phrasing and golden question would answer after them, and writes only if nothing else moves. Choosing an answer fix closes the other answer options as not chosen; text edits left unticked stay open on the card. Every apply backs up the FAQ file first and can be undone from History.
